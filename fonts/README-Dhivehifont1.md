# Dhivehifont1
By Fathimath Malaak Jaufar. A softer Thaana typeface derived from Noto Sans Thaana (Copyright 2022 The Noto Project Authors), licensed under the SIL Open Font License 1.1 (see OFL.txt).
Changes from Noto Sans Thaana: rounded/softened terminals and corners, 7% taller letterforms and fili, wider letter spacing for Thaana, tuned regular weight.
Rebuild: `python3 build.py` (fontTools, skia-python, skia-pathops).
